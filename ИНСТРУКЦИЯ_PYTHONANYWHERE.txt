ИНСТРУКЦИЯ: Как развернуть склад на PythonAnywhere (бесплатно, постоянно)

ШАГ 1: Регистрация
1. Зайдите на https://www.pythonanywhere.com/
2. Нажмите "Create a Beginner account" (бесплатно)
3. Заполните форму регистрации
4. Подтвердите почту

ШАГ 2: Загрузка файлов
1. Войдите в аккаунт PythonAnywhere
2. Перейдите в раздел "Files"
3. Создайте папку: складской-учет
4. Загрузите туда следующие файлы (кнопка "Upload a file"):
   - app.py
   - wsgi.py (ОБЯЗАТЕЛЬНО измените в нем "ВАШ_ЛОГИН" на ваш логин!)
   - requirements.txt
   - папку templates (заархивируйте в templates.zip, загрузите, затем распакуйте)
   - папку static (заархивируйте в static.zip, загрузите, затем распакуйте)

ШАГ 3: Создание веб-приложения
1. Перейдите в раздел "Web" (в верхнем меню)
2. Нажмите "Add a new web app"
3. Выберите "Manual configuration"
4. Выберите Python 3.10 (или новее)
5. В поле "Source code": /home/ВАШ_ЛОГИН/складской-учет
6. В поле "Working directory": /home/ВАШ_ЛОГИН/складской-учет

ШАГ 4: Настройка WSGI
1. В разделе "Web" прокрутите вниз до "WSGI configuration file"
2. Нажмите на ссылку (что-то вроде /var/www/ваш_логин_pythonanywhere_com_wsgi.py)
3. Удалите всё содержимое и вставьте:

import sys
import os

path = '/home/ВАШ_ЛОГИН/складской-учет'
if path not in sys.path:
    sys.path.append(path)

os.chdir(path)

from app import app as application

4. Нажмите "Save"

ШАГ 5: Установка зависимостей
1. Перейдите в раздел "Consoles" -> "Start a new console (Bash)"
2. Выполните команды:
   cd складской-учет
   pip install --user flask flask-sqlalchemy
3. Дождитесь установки

ШАГ 6: Запуск
1. Вернитесь в раздел "Web"
2. Нажмите зеленую кнопку "Reload ваш_логин.pythonanywhere.com"
3. Через 10-20 секунд перейдите по ссылке:
   http://ВАШ_ЛОГИН.pythonanywhere.com

ГОТОВО! У вас есть постоянная ссылка, которая работает 24/7

ВАЖНО:
- База данных (warehouse.db) создастся автоматически при первом запуске
- Фотографии загружаются в static/uploads/
- Ссылка постоянная: http://ВАШ_ЛОГИН.pythonanywhere.com
- Любой человек в мире может открыть эту ссылку и работать со складом

ОГРАНИЧЕНИЯ БЕСПЛАТНОГО ТАРИФА:
- Сайт "засыпает" после 3 месяцев бездействия (но данные сохраняются)
- Максимум 512 МБ места
- Для склада этого более чем достаточно
